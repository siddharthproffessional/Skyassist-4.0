# n8n integration

Five importable workflows live in `n8n/workflows/` (generated by `n8n/build_workflows.py`):

| File | Webhook path | Calls | Challenge |
|---|---|---|---|
| `A_disruption.json` | `skyassist/disruption` | `POST /v1/rebooking/jobs` | U-4.1 |
| `B_crew-message.json` | `skyassist/crew-message` | `POST /v1/crew/messages` | U-4.2 |
| `C_maintenance-signoff.json` | `skyassist/maintenance-signoff` | `POST /v1/maintenance/signoffs` | U-4.3 |
| `D_baggage-check.json` | `skyassist/baggage-check` | `POST /v1/baggage/feasibility` | U-4.4 |
| `E_state-change.json` | `skyassist/state-change` | `POST /v1/state-changes` | U-4.5 |

Each is **Webhook → Code (verify inbound HMAC, sign outbound) → HTTP Request → Respond**. n8n moves events; every
decision is made in SkyAssist. The exports contain **no credentials or secrets** (enforced by
`tests/test_n8n_workflows.py`); they read everything from the environment at run time.

## Setup (what we actually ran)

n8n 2.x needs Node ≥ 24.

```bash
npm install n8n
export SKYASSIST_API_BASE=http://127.0.0.1:8600
export SKYASSIST_SERVICE_TOKEN=...  SKYASSIST_WEBHOOK_SECRET=...   # same values as the SkyAssist API
export NODE_FUNCTION_ALLOW_BUILTIN=crypto N8N_RUNNERS_ALLOW_BUILTIN=crypto N8N_BLOCK_ENV_ACCESS_IN_NODE=false
for f in n8n/workflows/*.json; do npx n8n import:workflow --input="$f"; done
for id in a b c d e; do npx n8n publish:workflow --id=skyassist-$id; done
npx n8n start
```

Senders sign the compact JSON body: `X-SkyAssist-Signature: hex(HMAC-SHA256(secret, body))`. SkyAssist's outbox
does the same when `N8N_WEBHOOK_BASE` is set (otherwise events are marked `LOCAL_SIMULATED` and the OCC says so).

## Verified result

On 2026-11-20 the five workflows were imported into **n8n 2.48.7** (Node 24), activated, and driven end to end by
`scripts/n8n_e2e.py`: all five returned the expected SkyAssist decisions, a forged signature was rejected inside
n8n, and the API recorded each call with its n8n execution id. Full table: [`../results/n8n_e2e.md`](../results/n8n_e2e.md).

The public Streamlit demo does **not** run n8n; there the OCC shows "local simulation" for workflow delivery.
